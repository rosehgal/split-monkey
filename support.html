Split Monkey support

Common questions

I cannot find the shortcut. Install the latest Split Monkey build, tap Add Shortcut in the automation guide, and confirm Add Shortcut in Apple's preview. The ready-made shortcut ships with the app. On iOS 27 the automation arrives with the Message trigger already connected — open it in Shortcuts and turn on Automation. On older iOS, return to Split Monkey and it will open Shortcuts' Automation tab; create a Message automation, leave Sender empty, set Message Contains to one space character, and select the saved shortcut.

A message was not captured. Open Shortcuts → Automation and confirm the Message trigger, Message Contains set to one space character, Run Immediately (or Confirm Before Run turned off), and the Split Monkey action. This broad filter can capture non-bank messages too. If you used the app action directly, pass Shortcut Input to Transaction Text. After restarting the iPhone, unlock it once before relying on background capture.

An older “Split Easy” action appears. Remove that action from the personal automation and add the current Split Monkey action. Updating the app does not rename automations already saved in Shortcuts.

A group update would not merge. Confirm the link came from the intended person. Split Monkey rejects malformed links, different currencies, and conflicting edits to the same transaction rather than overwriting data.

I am changing phones or deleting the app. Your encrypted vault does not move to another phone and is not included in iCloud backup. Copy or share important group reports first. There is no vault recovery after the device is lost or the app is deleted.

A transaction is incorrect. Review and edit it before saving. You can also edit or delete a saved expense and undo a recorded settlement inside the group.
